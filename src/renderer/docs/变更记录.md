# 变更记录

## [1.2.0] — 2026-08-16

### 消息与输入体验

- **繁忙时 Enter 行为设置**：可配置 AI 繁忙时 Enter 排队等待 / 提示错误，前端排队队列 + dcp-message-id 标签剥离
- **草稿持久化**：草稿保存到 localStorage，重启应用不丢失
- **草稿跟随会话**：首页迁移、会话列表草稿标记、润色跨会话写回
- **润色直连**：润色改直连 DeepSeek API，会话进行时也能用
- **温和打断提示**：主动打断显示「已停止」，不再显示「错误: Aborted」

### 上下文与诊断

- **上下文面板 ACP**：接入 ACP 插件真实数据，支持一键解压查看内容
- **诊断面板 v1.2**：引擎日志关键词高亮与搜索，上下文口径统一（消息级 tokens）

### 文件与内容

- **右键插入路径**：不支持的文件类型右键添加时，路径直接插入输入框
- **文件修改卡片增强**：diff 展示行号（VSCode 风格），兼容 camelCase 工具入参，长路径单行省略
- **文件预览自动刷新**：按文件指纹判断会话编辑后自动刷新

### 通知与回合体验

- **回合完成计时修复**：每回合独立计时，serve 重启后继续旧会话仍准确
- **通知点击激活窗口**：点击系统通知激活分形窗口（最小化自动还原 + 置顶聚焦）
- **通知耗时格式化**：回答完成通知显示耗时时分秒格式化（12:03 / 1:00:00）
- **通知文案区分**：权限请求 / AI 提问使用不同文案

### 稳定性与引擎

- **acceptEdits 权限映射修复**：编辑/读取自动放行，启动与保存不再覆盖回 default
- **引擎升级**：sidecar 升级 OpenCode 1.18.18（Kimi/xai 修复）
- **下载校验**：下载脚本改用官方 asset digest，镜像优先下载
- **skill 节点显示**：收起态显示实际使用的 skill 名
- **润色状态隔离**：按会话隔离，切会话不再跨会话残留；空会话点新建跳转复用
- **更新检查修复**：安装版不再误报「开发模式不可用」

## [1.1.2] — 2026-08-14

### 通道安全

- **IPC 白名单防回归**：preload 白名单抽取独立模块 + 静态扫描测试，新增通道漏白名单会自动红
- **会话压缩修复**：session:compact 通道补白名单（渲染层 compactSession 调用原本会报 Channel not allowed）

### 更新体验

- **开发模式提示**：点击「检查更新」显示「开发模式不可用」，不再报内部错误
- **按钮对齐**：关于页「更新日志」「检查更新」并排对齐

## [1.1.1] — 2026-08-14

### 自动更新

- **自动检查更新**：启动后静默检查，发现新版自动弹窗提示
- **一键更新**：设置页「检查更新」手动检查，下载进度实时展示，下载完成一键重启安装
- **更新日志弹窗**：发版说明（Release Notes）随更新提示展示
- **构建发布**：electron-builder 24 → 26 升级，publish 切换 GitHub Releases

### 诊断面板重构

- **独立组件化**：诊断面板抽离为 DiagnosticsModal 组件，样式统一语义化
- **错误行高亮**：❌ 错误红色、⚠️ 警告黄色，问题一眼定位
- **复制语义化**：标签页内「复制当前标签页」+ 头部「复制诊断信息」全量打包
- **日志自动刷新**：引擎/控制台日志 3 秒轮询，无需手动刷新

### 稳定性修复

- **子任务失败原因透传**：失败卡片显示具体错误（如引擎过载），不再只有失败状态
- **消息时间线文字节点重复修复**：重放文本不再产生重复节点

## [1.1.0] — 2026-08-13

### 文件预览增强

- **PDF 预览**：内置 pdfjs 渲染，支持缩放/翻页/打印清晰度（DPR 适配）、快速翻页竞态防护
- **HTML 检查模式开关**：默认开启（点击元素出提示），可切换为「交互」模式让页面自身交互生效（hover 菜单/下拉/标签页），动态元素可被选中
- **HTML 导出 PDF**：一键导出当前 HTML 预览为 A4 PDF（隐藏窗口 printToPDF，无闪烁）
- **统一确认弹窗**：原生 confirm 替换为 ConfirmDialog（删除文件/关闭未保存/office 附件确认）

### 聊天与消息流

- **文件修改卡片**：回合结束自动提取 write/edit 工具修改的文件，以卡片形式挂载在回合末尾；同文件多次修改合并去重，新文件识别为「新增」
- **补充消息打断**：处理中输入文字可打断当前回合立即发送（Claude Code/Cursor 行为）
- **只发附件**：不输入文字也可发送附件（附件本身是发送内容）
- **office 附件弱提示**：模型端不支持读取的 office/二进制附件显示黄色警告三角，发送前二次确认
- **总结节点平滑展开**：输出完成时总结节点平滑展开，消除下方内容跳动

### 计费与上下文

- **人民币计费**：成本显示改为 ¥（DeepSeek 人民币计价），按本地价格表计算缓存命中/未命中/输出成本
- **余额查询**：设置面板与上下文面板显示 DeepSeek 账户余额，支持一键刷新
- **上下文占用修正**：修复指示器超估（重复累加），改为最后一条请求的真实输入
- **模型显示修复**：上下文面板模型行显示真实模型名（不再显示 --）

### 稳定性与引擎

- **OC v1.18.16 升级**：sidecar/依赖/下载脚本/版本矩阵同步
- **多窗口事件路由**：每个窗口独立订阅 + 按工作区目录路由事件，多窗口互不干扰
- **question 跨工作区修复**：提交答案不再 404（serve 多实例按目录路由）
- **serve 重启兜底**：请求超时自动中断（不再永久卡 loading），超时后主动取消生成
- **测试连接校验 API Key**：真实调用 DeepSeek 验证，无效 Key 直接提示
- **权限放行**：opencode 工具临时目录放行，subagent 不再因权限询问卡死

## [1.0.0] — 2026-08-10

### 全新引擎：OpenCode 驱动

- **内置 OpenCode 引擎**：DeepSeek 模型开箱即用——只需配置一个 API Key
- **serve 实时通信（SSE 事件流）**：流式消息、思考过程、工具调用全程可见
- **OC 是唯一引擎**：不再依赖任何其他 AI 工具

### 界面与交互

- **整体界面迁移 cc-gui 设计资产**：会话列表、消息时间线、文件管理、工具栏
- **会话按工作区组织**：多工作区切换互不干扰
- **消息锚点时间线**：快速跳转任意历史消息

### 配置与预置

- **类 VSCode settings.json 配置体系** + JSON Schema 校验，让 agent 帮你改配置
- **内置 MCP / skills / 插件预置包**：首次启动自动初始化，零概念门槛

### 安装与诊断

- **安装路径可选、桌面快捷方式可选**（辅助安装器向导）
- **应用内诊断面板**：引擎日志实时可读，30 秒无响应自动弹出提示
- **npm run debug 一键启动**：DevTools + serve 日志双通道排查
