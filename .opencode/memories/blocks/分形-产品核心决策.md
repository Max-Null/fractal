# 分形产品核心决策

## 事实
分形（oc-gui）是面向非编程人员的 OpenCode 桌面 GUI，工作区 H:\MaxNull\WorkStation\fractal，完整方案在 docs/设计/分形-设计方案.md（含附录 A 协议结论/B 实测指南/C 待实测清单）。

- OC 唯一引擎（ACP 双工协议），无任何 CC 代码；DeepSeek 唯一模型（OC 内置 provider），API Key 唯一必填
- UI 整体迁移 cc-gui 设计资产，StreamFrontendEvent 契约不变 → 前端零改造
- 配置类 VSCode settings.json，agent 可自检自改；交付内置 OC sidecar 开箱即用
- 实施顺序：阶段 0 实测 opencode acp 报文优先，结论回填附录 C
