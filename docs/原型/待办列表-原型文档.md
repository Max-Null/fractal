## 一、用户场景

| 场景 | 用户 | 描述 |
|------|------|------|
| 瞥一眼就知道在干嘛 | 普通用户 | 待办面板收着时，能看到「当前正在做的任务」和它的序号，不用展开 |
| 任务变化不遗漏 | 普通用户 | 引擎新建/更新待办时，面板自己展开 15 秒让你看到变化，然后自动收起 |
| 不用点击 | 普通用户 | 鼠标移到面板上就展开、移开就收起 |
| 一眼区分状态 | 普通用户 | 完成的=主题蓝、进行中的=主题蓝虚线框、没开始的=灰色常规 |
| 完成留痕 | 普通用户 | 待办全部完成后，面板收起，这一轮待办作为记录贴在对话最后；换会话/重启也能看到历史记录 |

## 二、核心规则表

| 规则 | 说明 |
|------|------|
| 折叠显示 | 「②/ ④ 列出 docs 目录结构」——当前进行中项（序号/总数 + 内容）；没有进行中的显示第一项未开始 |
| 自动展开 | 待办生成或变化时展开，15 秒无变化自动收起；频繁变化会重新计时 |
| 悬停展开 | 鼠标移入面板展开，移出收起；自动展开的 15 秒内鼠标在面板上，到期不收起 |
| 完成样式 | 主题蓝（不划掉） |
| 进行中样式 | 主题蓝 + 虚线边框 |
| 未开始样式 | 灰色常规（现状） |
| 完成留痕 | 全部完成 → 面板收起消失，对话尾部出现「📋 待办 4/4 · 时间」记录卡（默认折叠，点击展开明细） |
| 历史可见 | 切换会话/重启应用后，之前的完成记录仍能看到（每轮一条，按时间排） |
| 未完成中断 | 回合结束但待办没做完 → 面板保持折叠态（不生成记录卡），下次继续 |

## 三、界面布局

### 3.1 折叠态（常态）

```
┌─────────────────────────────────────────────┐
│ 📋  ②/ ④  列出 docs 目录结构          [3/4 ✓] │
└─────────────────────────────────────────────┘
```

### 3.2 展开态（hover 或自动展开）

```
┌─────────────────────────────────────────────┐
│ 📋  待办任务                          [3/4 ✓] │
│  ─────────────────────────────────────      │
│  ✓  ①  分析项目文档结构                [蓝]  │
│  ✓  ②  列出 docs 目录结构              [蓝]  │
│  ●  ③  整理方案文档  ← 虚线蓝框       [蓝]  │
│  ○  ④  提交变更                        [灰]  │
└─────────────────────────────────────────────┘
```

### 3.3 记录卡（回合完成后，消息流尾部）

```
┌─────────────────────────────────────────────┐
│ 📋 待办 4/4 完成 · 14:30                    │
│  （点击展开）                               │
│  ✓ 分析项目文档结构                         │
│  ✓ 列出 docs 目录结构                       │
│  ✓ 整理方案文档                             │
│  ✓ 提交变更                                 │
└─────────────────────────────────────────────┘
```

## 四、交互流程

### 4.1 悬停展开

1. 鼠标移入面板 → 展开全部待办
2. 鼠标移出 → 收回成「当前任务」一行

### 4.2 自动展开

1. 引擎新建/更新待办（面板当前收着）→ 面板自动展开
2. 15 秒内无新变化 → 自动收起
3. 变化频繁（每步勾选）→ 计时不断重置，任务做完才收起

### 4.3 完成留痕

1. 最后一项待办完成（引擎写入全完成列表）→ 面板收起消失
2. **该轮会话消息尾部**出现「📋 待办 4/4 · 时间」记录卡（紧贴最后一条消息）
3. 点击记录卡 → 展开明细（✓ 每项内容）
4. 新任务开始（新待办）→ 面板重新出现

## 五、异常分支

| 分支 | 用户看到什么 |
|------|-------------|
| 快照保存失败（磁盘问题） | 记录卡本轮仍显示（内存）；重启后该轮记录可能丢失 |
| 记录文件损坏 | 不显示记录卡（无报错打扰） |
| 待办从没完成（中断会话） | 面板保持折叠态；无记录卡（下次打开会话还能看到未完成待办） |
| 同一会话两个窗口同时操作 | 最后一次保存生效 |

## 六、测试要点（用户视角）

| 场景 | 操作 | 预期 |
|------|------|------|
| 折叠信息 | 收起状态看面板 | 显示当前进行任务 + 序号 |
| 悬停 | 鼠标移入/移出 | 展开/收起 |
| 自动展开 | 引擎新建待办 | 自动展开，15s 收起 |
| 状态颜色 | 查看三项状态 | 蓝/蓝虚线/灰 |
| 完成留痕 | 全部完成后看对话尾部 | 记录卡出现，面板消失 |
| 历史 | 切会话再切回 | 记录卡还在 |

---

## 七、边界与约束

| 约束 | 说明 |
|------|------|
| 记录位置 | 记录卡**贴在该轮最后一条消息后**（数据来自 OC 消息历史中的待办工具调用，纯 serve 数据） |
| 记录完整性 | 引擎每轮都会写完整待办列表（工具调用 input 全量回显）——历史可完整回溯 |
| 数据归属 | 待办状态本体 + 历史记录全部存在 OC 引擎（分形零存储，回到 serve 唯一源基线） |
| 手动编辑 | 不支持手动增删改待办（引擎驱动） |
