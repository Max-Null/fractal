## 一、用户场景

| 场景 | 用户角色 | 需求描述 |
|------|----------|----------|
| 看懂助手干了什么 | 普通用户 | 一次回复里「思考→工具→子智能体→文字→总结」的顺序一眼可见 |
| 不被思考过程打扰 | 普通用户 | 思考默认折叠成一行（带方向梗概），想看了再点开 |
| 工具干了什么 | 普通用户 | 工具一行标题（图标+梗概如「read · 文件路径」），点开看参数和结果 |
| 感知进度 | 普通用户 | 节点有「进行中（跳动动画）/完成（✓+耗时）」两态 |
| 回合边界 | 普通用户 | 回合结束有完成标记（耗时+系统时间）——最后操作是工具静默结束也有 |
| 跟踪子智能体 | 普通用户 | 子智能体卡片在时间线里，归属位置清晰，功能不变 |
| 找回自己的消息 | 普通用户 | 导航只列自己的消息，按「我什么时候说的」回溯 |
| 识别指令 | 普通用户 | 发 @侦查兵 或 /review 时气泡上有小徽标 |

## 二、核心规则表

| 规则 | 说明 |
|------|------|
| 对话布局 | **左右对话**：分形在左（logo 头像 + 时间线），你在右（圆形头像 + 发送时间 HH:mm:ss + 右侧气泡）；双方限宽各 90% |
| 用户消息 | 右侧独立气泡；带 @agent/斜杠命令时左上角小徽标；名行显示发送时间 |
| 助手回复 = 一条时间线（回合级） | 一次回复（你发消息 → 回复结束）= 一条时间线；过程分多步也不断开，节点按顺序连成一条线 |
| 节点两态 | 进行中：琥珀脉冲 + 三连点跳动 + 内容实时更新；完成：✓ + 耗时 |
| 思考过程 | 默认折叠：「💭 思考 + 方向梗概（前 60 字）+ 耗时」——点开展开全文；连续多段思考合并为一个节点 |
| 文字回复 | 始终展开（**不显示耗时**）；最后一段文字标为「✅ 总结」（绿色边框） |
| 工具调用 | 一行卡片：「icon + 工具名 + 梗概 + ✓ 完成 + 耗时」——点开看 input/result |
| 相邻同类合并 | 连续思考/文字合并为一个节点（工具打断后各自独立） |
| 子智能体 | **不单独显示 task 工具节点**——直接由子智能体卡片（🕵️ agent名 + 任务 + 状态）代替；启动瞬间显示「正在启动子智能体」+ 三连点；节点圆点为红色 |
| 待办更新 | 单行：「📋 更新待办 · 正在：<任务>」——**点击展开整个待办列表**；全部完成时标题变「待办完成」+ ✓；进行中不显示 ✓ |
| 回合完成标记 | 时间线末尾：「─── ✓ 已完成 · 耗时 · 时间 ───」——静默结束也有 |
| 会话标题 | 新会话首条消息后自动生成标题（OC 原生机制），会话列表同步更新 |
| 时间线导航 | 只列你自己的消息（圆点锚点），点击跳转 |

**元素明细**：

| 元素 | 类型 | 状态 | 交互 |
|------|------|------|------|
| 分形头像 | 圆形 logo（蓝底 logo.svg） | 常显 | 纯展示 |
| 用户气泡 | 右侧圆角卡片（圆形头像+发送时间） | 常显 | 指令徽标 @agent 紫 / 命令 蓝 |
| 思考节点 | 卡片（琥珀边框 💭） | 默认收起（梗概+耗时） | 点击展开全文 |
| 工具节点 | 卡片（蓝 icon 细分） | 默认收起（梗概+耗时） | 点击展开 input/result |
| todo 节点 | 单行（📋 主题色圆点） | 常显（busy 无 ✓） | **点击展开待办列表**；全完成显示「待办完成」 |
| 子智能体节点 | 卡片（🕵️ 红色圆点） | 收起/运行中动画 | SubTaskCard 现有（展开/监视/详情）；启动瞬间显示「正在启动子智能体」 |
| 文字节点 | 无卡片（正文） | 始终展开 | 无收起 |
| 总结节点 | 绿边框（✅） | 始终展开 | 无收起 |
| 进行中动画 | 卡片+圆点 | 琥珀脉冲+三连点跳动 | 内容实时更新 |
| 回合完成标记 | 分隔线「✓ 已完成」 | 完成即显示 | 纯展示 |

## 四、交互流程

```mermaid
sequenceDiagram
    actor 用户
    participant 消息流
    participant 时间线

    用户->>消息流: 发送「@侦查兵 查版本」
    消息流->>消息流: 气泡显示 [@侦查兵] 徽标
    用户->>消息流: 助手开始回复
    消息流->>时间线: 思考节点（进行中·梗概跳动）
    消息流->>时间线: 子智能体节点（「正在启动」→ running 动画）
    消息流->>时间线: 工具节点逐个出现（完成态）
    消息流->>时间线: 文字节点（增量展开）
    消息流->>时间线: 回合完成标记（✓ 已完成 + 耗时 + 时间）
    消息流->>消息流: 首条消息后自动生成会话标题（列表同步）
    用户->>时间线: 点击工具节点
    时间线->>时间线: 展开 input/result
    用户->>时间线: 点击导航（自己的消息）
    时间线->>消息流: 滚动到对应回合 + 定位
```

## 五、边界与约束

| 边界 | 说明 |
|------|------|
| 思考收起也完整保存 | 收起只是视觉折叠，数据完整 |
| 工具结果太长 | 展开截断（现有机制），完整在诊断日志 |
| todo 详情 | 点击 todo 节点展开列表；完整操作在独立待办面板 |
| 旧会话 | 无 contentBlocks 的老消息降级为三段式（顺序退化可接受） |
| 子智能体归属 | 实时=task 工具出现位置（子智能体卡片代替 task 节点）；历史=对应消息；无法锚定→独立节点段；启动窗口显示「正在启动子智能体」占位 |
| 导航只有用户消息 | 不列思考/工具/子智能体节点 |
| 会话标题 | 依赖 OC small_model 配置；未配置时标题保持「新会话」（已知限制） |

## 六、测试要点（用户视角）

| 测试场景 | 操作 | 预期结果 |
|----------|------|----------|
| 看懂时间线 | 复杂任务（多工具+子智能体+多次思考） | 竖线+节点顺序清晰，思考/文字交替正确 |
| 收起态梗概 | 找有思考/工具的回合同合 | 标题行显示内容梗概（read 显示文件名、bash 显示命令等） |
| 进行中动画 | 发任务观察 | 节点脉冲+三连点跳动，内容实时更新，进行中无 ✓ |
| 静默结束 | 发任务让模型最后只跑 shell | 回合完成标记仍显示 |
| todo 节点 | 让助手建待办 | 一行显示「正在：X」；点击展开待办列表；全部完成显示「待办完成」+ ✓ |
| 指令徽标 | 发 @侦查兵 / /review | 气泡徽标显示 |
| 导航回溯 | 长会话滚动 | 导航只列你的消息，点击跳转 |
| 子智能体 | 历史会话 + 实时执行 | 卡片在对应消息位置；启动瞬间显示「正在启动子智能体」；功能（展开/详情）不变 |
| 会话标题 | 新建会话发首条消息 | 标题自动生成并同步到会话列表 |
| 左右布局 | 任意会话 | 分形在左（logo 头像），用户在右（发送时间），限宽对称 |
| 旧会话 | 打开老消息 | 降级三段式显示，不报错 |
