## 交互说明（两版通用）

- 引导页（2 步：API Key → 测试连接）→ 进入主界面
- 顶栏太阳按钮：明暗主题切换
- 右侧面板 5 个 tab：文件 / 记忆 / 状态 / 计划 / 预置
- 输入框发送：模拟流式输出 + 工具卡片 + 权限审批弹窗
- 侧栏「＋」新建会话（空态 + 快捷入口）
- 顶栏齿轮：设置视图（简单/高级 JSON 编辑）
