# V2 状态指示器 - 原型文档

版本：v1.0 · 2026-08-09 · 产品/测试

## 一、用户场景

1. 用户同时开着 OpenCode 官方桌面端和分形——进入分形主界面时看到顶部提示「V2 API 服务不可用」，右上角 V2 胶囊是红色
2. 用户点击红色 V2 胶囊 → 弹窗解释 V2 是什么、为什么不可用、怎么恢复
3. 用户关闭官方桌面端后点「重新检测」→ V2 恢复可用（胶囊变主题色）
4. 用户平时不关心——V2 胶囊静静待在顶栏（主题色），点开也能看 V2 是什么

## 二、核心规则表

| 规则 | 产品语言 |
|------|---------|
| 状态判断 | 分形启动时自动检测 V2 服务（端口 8800 是否被占用）——不用用户操作 |
| 载入提示 | 进入主界面时如果 V2 不可用，顶部弹一条轻提示（一次会话只弹一次，可自动消失） |
| V2 按钮 | 右上角「V2」小胶囊：可用=主题色，不可用=红色；悬停显示当前状态 |
| 详情弹窗 | 点 V2 胶囊弹出：V2 是什么 + 当前状态 + 原因 + 恢复方法 |
| 重新检测 | 不可用时弹窗里有「重新检测」按钮（重启引擎重新判断） |
| 功能影响 | **没有任何功能影响**——分形全部功能走 V1 API，V2 只是状态透明 |

## 三、布局示意

```
┌──────────────────────────────────────────────────────┐
│  ⬡ 分形  📁 H:\WorkStation\fractal      🌙 ⚙  [V2] │ ← 顶栏右侧（主题按钮旁）
└──────────────────────────────────────────────────────┘
   │
   ├── 载入完成提示条（仅不可用时，3 秒自动消失）：
   │    ⚠ V2 API 服务不可用（端口 8800 被占用）——点右上角 V2 查看详情
   │
   └── 主界面正常（不受影响）
```

## 四、交互流程

### 4.1 载入提示（不可用场景）

```
进入主界面 → v2 不可用 且 本次会话未提示过？
  ├─ 是 → 顶部提示条 3 秒（记一次）
  └─ 否 → 无动作
```

### 4.2 V2 详情弹窗

```
点击 V2 胶囊 → 弹窗：
  ┌──────────────────────────────────────┐
  │ V2 API 状态                          │
  │                                      │
  │ V2 是什么：新一代 API（官方桌面端已   │
  │ 迁移）；分形主要用 V1，功能完整       │
  │                                      │
  │ 当前状态：● 可用（绿）                │
  │       或：✗ 不可用（红）——端口 8800  │
  │          被占用（通常官方桌面端/TUI） │
  │                                      │
  │ [重新检测]（仅不可用）                │
  └──────────────────────────────────────┘
```

## 五、状态矩阵

| 场景 | V2 胶囊 | 载入提示 | 弹窗状态区 | 重新检测 |
|------|---------|---------|-----------|---------|
| 8800 空闲（正常） | 主题色 | 无 | ● 可用 | 无（隐藏） |
| 8800 被官方端/TUI 占用 | 红色 | 提示条一次 | ✗ 不可用 + 原因 | 显示 |
| 重启 serve 后 8800 释放 | 主题色（自动恢复） | 无（已提示过） | ● 可用 | 无 |

## 六、测试要点（用户视角）

1. 正常启动（8800 空闲）→ 无提示条 + V2 胶囊主题色
2. 模拟 8800 被占 → 进入主界面提示条出现一次 + 胶囊红色
3. 同一会话再次进入（切会话/重连）→ 提示条不再弹（记过一次）
4. 点红色胶囊 → 弹窗三块内容完整（是什么/状态/原因）
5. 点「重新检测」→ 引擎重启 → 状态更新
6. 恢复后胶囊变主题色、弹窗状态区变可用

## 七、边界与约束

- 提示条是轻提示（3 秒自动消失），不打断使用
- 关闭官方桌面端后需「重新检测」或重启分形才恢复（v2 状态在引擎启动时判定）
- V2 不可用 ≠ 分形不可用——所有功能照常
