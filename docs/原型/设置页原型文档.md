## 一、用户场景

| 场景 | 用户故事 |
|---|---|
| 基础配置 | 作为新用户，我想在设置页填入 API Key 并测试连接，以便开始使用 |
| 界面个性化 | 作为日常用户，我想切换语言/主题/字号，以便界面符合我的习惯 |
| 权限控制 | 作为谨慎用户，我想设置权限模式（询问/自动编辑/全自动/计划），以便控制引擎的操作范围 |
| 数据隔离 | 作为关心隐私的用户，我想开启「独立会话数据」，以便分形只见自己创建的会话（与其他工具隔离） |
| 无缝接管 | 作为从官方桌面端/CLI 迁移的用户，我想关闭「独立会话数据」（默认 ON），以便继续共享数据目录的旧对话 |

## 三、元素与交互

### 3.1 数据模式开关（新增，核心）

| 元素 | 说明 |
|---|---|
| 位置 | 高级设置折叠区内、JSONC 编辑器上方 |
| 开关 | 切换控件（默认 ON=独立）；OFF 时关态灰色 |
| 文案 | 标题「独立会话数据」+ 说明「开启后会话只保存在本应用的数据目录，与其他工具隔离」 |
| 切换反馈 | 状态提示「正在重启引擎…」→ 完成提示「引擎已重启：独立会话数据模式」；失败提示「引擎重启失败，已恢复原模式」 |
| 切换后 | 会话列表变为新数据目录的内容（首次开启为空列表——属正常） |

### 3.2 既有分区（交互不变，盘点确认）

| 分区 | 元素 | 交互 |
|---|---|---|
| LLM 设置 | API Key（密码框）/ 接口地址 / 上下文窗口（1M/128K 解析）/ 推理请求地址 / 测试连接 | 测试连接转圈 + 成功/失败提示；上下文窗口失焦解析 |
| 工作区 | 当前工作区（只读路径）+ 浏览 | 点击浏览弹目录选择器 |
| 界面设置 | 模型（flash/pro）/ 语言 / 主题 / 字号 / 权限模式 / 思考深度 / 重新显示引导页 | 下拉单选（当前项高亮）；权限 4 项带图标+CLI 说明；思考深度按模型变体动态 |
| 高级设置 | JSONC 编辑器 | 折叠展开 |
| 关于 | 分形版本 / OC 引擎版本 / 预置包版本 / 变更日志 | 变更日志弹窗 |

## 四、状态与反馈

| 状态 | 表现 |
|---|---|
| 测试连接中 | 按钮转圈 + 禁用 |
| 数据模式切换中 | alertText「正在重启引擎…」（顶部提示条） |
| 引擎重启失败 | 开关回滚 + 报错提示条 |
| 独立模式首次进入 | 会话列表空（正常）——开关说明文案已在设置页 |
| 引擎未就绪（设置页打开时） | 版本显示「—」兜底 |

## 五、测试要点（用户视角）

| 用例 | 预期 |
|---|---|
| 打开设置页 | 六区 + 关于三行版本正常渲染 |
| 默认数据模式 | 开关 ON（独立） |
| 打开开关 | 引擎重启提示 → 完成后会话列表切换到独立目录（首次为空） |
| 关闭开关 | 引擎重启 → 共享会话恢复（之前会话还在） |
| 快速反复切换 | 引擎重启期间开关禁用（isRestarting 锁），重启完成前不可再次点击；无竞态崩溃 |
| 切换失败（模拟引擎异常） | 开关回滚 + 错误提示 |

## 六、边界与约束

- 数据模式只影响**会话数据**（storage/log/repos），不影响配置（agents/skills/key 始终独立）
- 两套数据目录并存（共享 + 独立），切换即切换可见会话，数据互不删除
- 卸载重装不自动清理任何数据目录
