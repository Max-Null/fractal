## 依赖关系

```
B1 配置 UI → 独立，先行
③（完成）→ ④（依赖卡片形态）
① → ②（虚拟滚动需要①的列表结构） | ① → ⑤（详情面板复用①数据）
① 的搜索增强 ↔ B3 会话搜索（合并实施）
B2 自动更新 ↔ 发版流程（需要更新服务器）
C 组三项互相独立，与 A/B 组无依赖
```
