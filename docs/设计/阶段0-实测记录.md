## 一、踩坑记录（教训，GUI 实现时复用）

| # | 现象 | 根因 | 解法 |
|---|------|------|------|
| 1 | `@opencode-ai/sdk does not provide an export named default` | SDK 无 default 导出 | `import { createOpencodeClient } from "@opencode-ai/sdk"` |
| 2 | spawn 后报「不是有效的 Win32 应用程序」 | npm shim 是 .cmd，Node CreateProcess 不解析 | 解析 shim 到原生 exe：读 `.cmd` 内 `node "%~dp0…\opencode.exe"` 目标（`resolveOpencodeBin()`） |
| 3 | `shell:true` 启动后进程无法 kill（工具层清理异常） | cmd → node → serve 三层进程树 | 直接 spawn 原生 exe，避免中间层 |
| 4 | SDK 请求全部 401 | @hey-api `createClient` 配置键是 `headers` 不是 `defaultHeaders` | `createOpencodeClient({ headers: { Authorization: … } })` |
| 5 | serve 默认要求认证 | v1.15+ serve 默认 Basic auth | env `OPENCODE_SERVER_USERNAME` / `OPENCODE_SERVER_PASSWORD` 注入；Basic 头 `btoa(user:pass)` |
| 6 | PowerShell 管道吞子进程输出 | 管道缓冲 | 输出重定向到文件再读（`*> file 2>&1` + Get-Content） |
| 7 | serve-stdout.log 读乱码 | opencode 输出 UTF-16 | `Get-Content -Encoding Unicode` |
