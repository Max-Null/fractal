# 实现设计 06：应用配置体系

> 版本：2026-08-07 ｜ 规格依据：方案 3.8（配置分层/settings.json 设计/生效机制/Agent 协作流程）
> 前置阅读：00 总览、03 持久化（现有数据布局）

## 一、目标

API Key 唯一必填；高级配置类 VSCode settings.json；**agent 可自检、自修改配置**（用户一句话让 agent 帮忙改设置）。

## 二、配置分层（方案 3.8.1）

```
第 1 层：内置默认值（代码内置，只读）
第 2 层：用户 settings.json（%APPDATA%/oc-gui/settings.json，JSONC 可注释）
第 3 层：密钥（API Key）——隔离存储
```

## 三、现状 vs 目标（阶段 6 改造点）

| 项 | 现状 | 目标 |
|----|------|------|
| 设置文件 | 散：ui-settings.json + localStorage + provider-configs.json | 统一 settings.json（JSONC）+ schema 校验 |
| API Key | provider-configs.json 明文（agent 读不到——userData 不在工作区，天然隔离） | 保持明文存储（serve 配置必须明文）；safeStorage 加密为可选加固 |
| 生效机制 | 保存即重启 serve（saveProviderConfig 联动） | 文件监听（fs.watch）→ schema 校验 → config-changed 广播 → 前端刷新 + 引擎项增量同步 |
| 编辑器 | 无（设置面板表单） | SettingsJsonEditor.vue（CodeMirror JSONC + schema 提示） |
| Agent 协作 | 无（agent 不知道 settings.json） | 预置 permission allow settings.json 目录 read/edit/write；改完文件监听生效 |

## 四、实现要点

1. **electron/main/settings.ts**（新建）：默认值表 + settings.json 读写（JSONC 解析——用 jsonc-parser）+ schema 校验（ajv）+ fs.watch 监听 → config-changed 事件
2. **settings.schema.json**：方案 3.8.2 字段全集（ui.*/deepseek.model/agent.*/preset.*/engine.*）——表单与 agent 共用
3. **三条路径统一走文件**：GUI 表单（保存写文件）/ JSONC 编辑器（保存写文件）/ agent 工具（直接写文件）→ 监听生效，天然一致
4. **引擎联动**：settings.json 的引擎相关项（deepseek.model/agent.permissionMode/agent.effort）→ ensureConfig 增量同步 opencode.json（不重启，下次会话生效）
5. **非法值处理**：回退默认 + 警告（config-changed 事件带 warnings）
6. **Agent 权限预置**：oc-config 的 permission 规则加 settings.json 所在目录 allow（external_directory 或 read/edit 绝对路径）
7. **设置面板分层**：简单模式（表单）+ 高级模式（SettingsJsonEditor.vue）——面板加「高级设置」入口

## 五、验证方式（Agent 改配置闭环）

1. 临时会话让引擎（双星）读 settings.json（自检）
2. 让引擎改 `ui.theme` 为 light
3. 文件监听触发 → 前端主题即时切换（config-changed）
4. 非法值（如 ui.theme: "red"）→ 回退默认 + 警告提示
