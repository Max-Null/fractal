## 四、权限审批（round6 实测，核心 fixture）

**触发条件**：项目级 opencode.json 配置 `{"permission": {"*": "ask"}}` 且无放行插件。write/read/edit 全部触发。

**请求报文**（write 新建，完整结构）：

```json
{"jsonrpc":"2.0","method":"session/request_permission","params":{
  "sessionId":"ses_02cb0e3bdffeCK4l7zYysWtWfj",
  "toolCall":{
    "toolCallId":"call_00_07ltM9dJOtaRyMKhCjaV4785",
    "title":"C:\\...\\iso-write.txt",
    "kind":"edit","status":"pending",
    "locations":[{"path":"C:\\...\\iso-write.txt"}],
    "rawInput":{"filepath":"C:\\...\\iso-write.txt","diff":"Index: C:\\...\\iso-write.txt\n..."}
  },
  "options":[
    {"optionId":"once","kind":"allow_once","name":"Allow once"},
    {"optionId":"always","kind":"allow_always","name":"Always allow"},
    {"optionId":"reject","kind":"reject_once","name":"Reject"}
  ]
}}
```

- edit 类（write/edit）rawInput 含 **diff**（可渲染预览）；read 类 title="read"、rawInput 为空
- **响应格式（已实测验证）**：`{"jsonrpc":"2.0","id":<同请求 id>,"result":{"outcome":{"outcome":"selected","optionId":"once"}}}`——outcome 为**嵌套结构**
- 拒绝：`"outcome":{"outcome":"rejected"}`（或 optionId 非 once/always 时按 reject 处理）；取消回合响应 cancelled
- 响应 once → 仅本次放行；always → 该操作持续放行（对应分形「记住」→ 写 approved_scenarios）

**对分形设计的影响**：
1. 审批弹窗三按钮 = once/always/reject（「允许一次 / 始终允许 / 拒绝」）
2. edit/write 弹窗展示 diff 预览（rawInput.diff）
3. read 也会 ask → 预置权限应设计为：read/glob/grep/list 默认 allow，edit/write/bash/task 默认 ask（避免打扰）
4. 插件隔离：分形 sidecar 环境不得安装 opencode-acp 插件

## 五、流式事件结构（round3/round6 实测）

| 类型 | 字段（要点） | 分形映射 |
|------|-------------|----------|
| `agent_thought_chunk` | messageId + content{type:"text",text}，**逐 token** 推送 | thinking 累积（按 messageId） |
| `agent_message_chunk` | messageId + content{type:"text",text}，逐 token | 回复文本累积 |
| `tool_call` | toolCallId/title/kind/status:"pending"/locations:[]/rawInput:{} | tool_start |
| `tool_call_update` | toolCallId/status:"in_progress"\|"completed"\|"error"/kind/title/locations/rawInput/rawOutput/content | tool 状态流转；completed 时 content 含结果文本 |
| `usage_update` | used/size/cost{amount,currency} | 上下文指示器（ContextIndicator 数据源） |
| `available_commands_update` | availableCommands[{name,description}] | 预置 skills 暴露机制（含 skill 来源命令） |

**prompt 响应**（请求被接受后回合结束返回）：

```json
{"stopReason":"end_turn","usage":{"inputTokens":105,"outputTokens":3,"totalTokens":39670,"thoughtTokens":10,"cachedReadTokens":39552},"_meta":{}}
```

- stopReason：end_turn / cancelled（cancel 后）/ max_tokens / refusal
- 错误映射（源码）：MessageAbortedError→cancelled、MessageOutputLengthError→max_tokens、ContentFilterError→refusal、ProviderAuthError→ACP AuthRequiredError(-32000)

## 六、其他结论

- **cancel**：`{"jsonrpc":"2.0","method":"session/cancel","params":{"sessionId":"..."}}`（无 id 通知）
- **set_config_option**：`{sessionId, configId: "model"|"effort"|"mode", value}` → 返回更新后 configOptions
- **resume**：`{sessionId, cwd}` → 返回 configOptions，**无重放事件**（分形历史展示走本地 SQLite）
- **fork**：`{sessionId, cwd}` → 新 sessionId + 重放事件流（user_message_chunk/agent_thought_chunk/tool_call 等），前端需按 messageId 去重
- **list**：`{cwd}` → sessions[{sessionId,cwd,title,updatedAt}]，可用于分形 check_oc_session_exists
- **close**：`{sessionId}` → {}（分形删会话时调用）
- **模型配置**：用户全局用自定义 provider `ds`（@ai-sdk/openai-compatible + baseURL https://api.deepseek.com/v1），模型 ds/deepseek-v4-pro、ds/deepseek-v4-flash——C-5/C-6 确认：DeepSeek 走 OpenAI 兼容端点，模型 ID 以用户配置为准
- **sidecar 来源**：npm 包内嵌 `bin/opencode.exe`（174MB，bun 编译）——C-7 确认：官方 zip 解压产物即此形态
