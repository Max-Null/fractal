# 分形 0.1.0 发布说明（草案）

> 版本：0.1.0 ｜ 面向非编程人员的 OpenCode 桌面 GUI

## 新功能

- 内置 OpenCode 引擎（v1.18.14 sidecar），无需安装任何命令行工具
- 首次引导：2 步配置 API Key（DeepSeek）→ 测试连接 → 开箱即用
- 预置双星四 Agent 系统 + 15 个技能 + 分形插件（首次启动自动初始化）
- 聊天：AI 对话（思考/工具/回答分阶段展示、打字机流式、停止生成、待办面板）
- 工具审批弹窗（允许一次/总是允许/拒绝）+ 提问弹窗（单选/多选/自由输入）
- 工作区管理：切换目录会话列表自动跟随；最近工作区快速切换
- 会话管理：历史/重命名/删除/分叉
- 文件面板：文件树/Git 面板/文件预览；右侧 5 tab（文件/记忆/状态/计划/技能）
- 设置：API Key/模型/权限模式 + 高级配置 JSONC 编辑器（实时生效）
- 单实例保护（双开自动聚焦已有窗口）

## 重要说明（开发版升级用户）

- 如曾使用 0.1.0 之前的开发版：首次启动正式版前，建议删除 `<userData>\config\opencode\` 目录再启动（旧版内联 agent 占位可能与预置 agent 同名冲突）
  - userData 路径：`%APPDATA%\oc-gui\`

## 已知限制

- 模型：仅 DeepSeek（deepseek-v4-flash / deepseek-v4-pro）
- 附件/引用：界面支持，serve 端 FilePart 链路待完整验证
- 记忆/状态/计划/技能面板：UI 就绪，数据源逐步接入
