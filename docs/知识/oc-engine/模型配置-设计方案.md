# 模型配置-设计方案（oc-plus 交付，归档）

> **来源**：oc-plus 工作区会话交付（2026-08-09）
> **归档位置**：分形知识库 oc-engine（OC 机制知识）
> **分形实现**：模型槽位统一（applyModelAliases）已按本方案结论落地，见文末「分形实现对照」

## 真相源原则（2026-08-09 查证，两项目共享）

- **OC 加载顺序：全局 opencode.json → 项目 opencode.json → 最后 .md（覆盖 JSON）**
- 推论：deploy 部署的 .md 必然生效（不依赖 GUI）；**GUI 写 opencode.json 的 agent 段无效**（被 .md 覆盖）
- **.md 文件是模型配置的真相源，GUI 只是它的可视化编辑器**
- mtime 保护：GUI 改过（mtime 更新）的 .md 不被预置升级冲掉；oc-plus 重新 deploy 可夺回
- oc-plus 架构原则「医者不能自医」：真相源在文件层，GUI 是可选增强层；违背此原则的设计必须显式标注理由

## 章节

### 二、OC 机制查证

- **small_model 真实用途（源码证据）**：轻量任务模型（标题生成/会话摘要/压缩摘要），由 OC 引擎自动使用，独立于 agent 模型配置
- **子 agent 无 model 行 = 继承主模型（task.ts 证据）**：agent 配置缺 model 字段时，任务继承主会话模型——**不是**继承 small_model

### 三、Agent 模型分配表

| Agent | 模型 | 说明 |
|-------|------|------|
| 双星 | 主模型 | 用户选择的模型（HIGH） |
| 工匠/参谋/助理 | **显式写** flash/pro | 必须显式写 model 字段，否则继承 HIGH |
| 制图师 | kimi-k3 | 多模态（VISION） |
| 军师/导师 | 无 model 行 | 继承主模型 |
| small_model | 独立配 flash | 标题生成省钱，与 agent 模型各司其职 |

### 四、GUI 设计

- 设置页新增「Agent 模型」区（下拉选择、军师/导师锁定态提示、复用 saveProviderConfig 链路）

### 五、风险表

1. 误删 model 行成本回归（agent 无 model 行 → 继承 HIGH → 低成本 agent 变贵）
2. agent 名匹配（分配规则按 agent 名硬编码，改名需同步）
3. 军师跟随主模型（继承语义的预期行为，需文档化）
4. （其余按 oc-plus 会话补充）

## 关键结论（两文档共享）

- ✅ **「军师/导师 → 继承主模型」**：成立（源码证实）
- ❌ **「工匠/参谋/助理 → SMALL_MODEL=flash」**：不成立——必须显式写 model 字段，否则继承 HIGH
- 💡 **small_model 独立照配 flash**（标题生成省钱），机制上各司其职

## 分形实现对照（2026-08-09 已落地）

| oc-plus 结论 | 分形实现 | 位置 |
|---|---|---|
| 双星 = 主模型 | applyModelAliases 双星→HIGH（读 cfg.model，设置页联动） | `electron/main/preset.ts` |
| 工匠/参谋/助理显式写 | LOW 槽位显式替换（默认 SMALL_MODEL，可配置） | `electron/main/preset.ts` |
| 制图师 = kimi-k3 | VISION 槽位显式写 VISION_MODEL 常量 | `electron/main/oc-config.ts` |
| 军师/导师继承主模型 | 跳过无 model 行（天然继承） | `electron/main/preset.ts` |
| small_model 独立 flash | SMALL_MODEL 常量 + 设置页「轻量模型」下拉（resolveSmallModel） | `electron/main/oc-config.ts` + 设置页高级区 |
| **mtime 保护**（真相源） | initPreset agents 目录保护模式：目标比源新跳过；拷贝恢复源 mtime（否则二次升级全跳过） | `electron/main/preset.ts` copyDir/copyFileKeepMtime |
