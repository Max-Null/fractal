# v1.18.x — OC 数据格式约定

> 适用版本：v1.18.x | 最后验证：待实测 | 验证方式：oc-plus 实测 + 官方文档

## 文件/目录约定（oc-plus 已实测验证）

| 路径 | 用途 | 关键约定 |
|------|------|---------|
| `~/.config/opencode/` | 全局配置目录 | opencode.json、agent/、skill/、plugin/、commands/ |
| `~/.config/opencode/plans/` | 计划文档目录 | **路径固定不可变**（GUI 定位锚点）；`{日期}-{HHMM}-{slug}.md`；`.active.json` 跨会话状态 |
| `~/.config/opencode/memories/` | 记忆目录 | blocks/（pending/auto/suggest 子目录）、triggers/、events.log、debug.log、.assertion-counter.json |
| `~/.config/opencode/plugins/*.ts` | 插件 | Glob 一级匹配，子目录隔离工具模块 |
| `<项目>/.opencode/memories/` | 共享项目级记忆 | git 管理的团队规范 |
| AGENTS.md | 项目指令 | OC 自动注入，agents-priority 插件确保中文规范前置 |

## 知识块文件格式（oc-plus 约定）

```markdown
<!-- type: knowledge --><!-- status: pending --><!-- description: 一句话摘要 -->
<!-- priority: 45 --><!-- suggested_status: auto --><!-- memPathIndex: 2 -->

## 标题
正文（事实 → 原则 → 反例 → 结论，≤15 行）
```

## GUI 提取约定（方案已定，数据源锚点）

| GUI 面板 | 数据源 | 提取方式 |
|---------|--------|---------|
| 计划文档 | `~/.config/opencode/plans/*.md` | 文件系统读取，过滤已完成，按 mtime 排序 |
| 待办列表 | 消息流 `todowrite` | 取最新一条 call 的 `state.input.todos` |
| 修改文件统计 | 消息流 `edit`/`write` | 对 `args.filePath` 去重统计 |
| 记忆面板 | `~/.config/opencode/memories/` | Rust 桥接读文件，前端复用知识引擎（oc-plus engine/）做搜索 |

## 注意

- 数据格式变化属「配置/数据」影响面，升级时回填本文件
- 记忆面板依赖本文件约定：status 子目录结构 + 元数据头解析（KnowledgeEngine.parseMeta）
