# v1.18.x — ACP 协议

> 适用版本：v1.18.x | 最后验证：待阶段 0 实测 | 验证方式：agentclientprotocol.com（Anthropic）+ 实测报文（docs/实测记录.md）

## 传输模型

- stdin/stdout 双工，每行一个 JSON（NDJSON），JSON-RPC 2.0
- 命令：`opencode acp [--cwd <dir>]`，长驻进程，stdin EOF 退出

## Client → Agent 方法（待实测确认）

| 方法 | 参数 | 用途 |
|------|------|------|
| `initialize` | 协议版本、能力协商 | 握手，确认 `agentCapabilities`（resume/fork/mcp） |
| `session/new` | `cwd`、`mcpServers`、`additionalWorkspaceRoots` | 创建会话（⚠️ C-1：是否支持指定模型，待实测） |
| `session/prompt` | `sessionId`、`ContentBlock[]` | 发送消息，进度经 session/update 推送 |
| `session/cancel` | `sessionId` | 取消回合 |
| `session/resume` | `sessionId` | 恢复会话（⚠️ C-4：重放体积待实测） |
| `session/close` | `sessionId` | 关闭会话 |
| `session/list` | — | 会话列表（check_oc_session_exists 依赖） |
