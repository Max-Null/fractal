# v1.18.x — OC 插件 API

> 适用版本：v1.18.x | 最后验证：待实测 | 验证方式：官方文档（opencode.ai/docs/plugins）+ 源码阅读（anomalyco/opencode）+ 实测

## 插件加载机制

- [ ] 自动发现：`{plugin,plugins}/*.{ts,js}`（Glob 只匹配一级文件，子目录隔离工具模块——oc-plus 实测结论）
- [ ] 插件签名：`(input: PluginInput)` 函数式 vs 对象直出（oc-plus 踩坑：懒加载、副作用危害）
- [ ] 插件名与文件一致性（`"fractal"` 必须与 `plugins/fractal.ts` 一致）
- [ ] 依赖：`@opencode-ai/plugin` SDK 版本对齐
