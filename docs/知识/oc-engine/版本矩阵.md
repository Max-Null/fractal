## 影响面分类（升级五步流程第一步用）

| 分类 | 含义 | 处理 |
|------|------|------|
| **协议** | ACP 报文结构/方法变化 | 更新 v1.18.x-ACP协议.md + 契约测试 fixture |
| **插件 API** | hook 签名/PluginInput/事件类型变化 | 更新 v1.18.x-插件API.md + oc-plus 适配 |
| **配置** | opencode.json schema 变化 | 更新 v1.18.x-配置schema.md + oc_config.rs |
| **无影响** | TUI/Desktop/文档类 | 仅记录，不动作 |

## 仓库与版本来源

- 仓库：github.com/anomalyco/opencode（⚠️ 2026-08 从 sst/opencode 迁移，官方文档 opencode.ai 已指向新地址）
- Release 列表：GitHub Releases（独立二进制 `opencode-windows-x64.zip` 等，v1.18.13 已验证）
- 依赖版本对齐：`~/.config/opencode/package.json` 中 `@opencode-ai/plugin` / `@opencode-ai/sdk` 与 CLI 版本一致
