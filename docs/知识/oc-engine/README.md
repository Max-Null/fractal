# OC 引擎知识库（oc-engine）

> 面向分形开发者的 OpenCode 深入理解沉淀库——带版本号、随 OC 迭代持续维护。
> 背景：OC 更新极快（v1.18.13 于 2026-08-04 发布，几乎每日发版）。分形把 OC 当基座但**绝不改源码**（方案 D14），本库是跟随迭代的生存工具。

## 知识三通道

1. **官方文档**：opencode.ai/docs（Config/Providers/Plugins/ACP/Agents/Skills/Permissions/MCP/LSP 等 20+ 页面）
2. **OC 源码只读阅读**：anomalyco/opencode `packages/opencode/src/`（acp/、plugin/ 等）——**只读不改**
3. **实测**：阶段 0 的 ACP 真实报文（`docs/实测记录.md`）+ 契约测试 fixture（`src-tauri/tests/fixtures/`）

## 使用规则

- 头部版本锚点格式：`> 适用版本：v1.18.13 | 最后验证：2026-08-05 | 验证方式：...`
- 升级 OC 前**必须先**更新本库（升级五步流程第一步）
- 新知识来源优先标注「验证方式」，未实测的结论禁止标注「已验证」
