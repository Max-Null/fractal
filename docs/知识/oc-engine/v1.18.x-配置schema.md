# v1.18.x — opencode.json 配置 Schema

> 适用版本：v1.18.x | 最后验证：待实测 | 验证方式：官方文档（opencode.ai/docs/config）+ 源码 + models.dev

## 关键字段（附录 A.3 结论，待逐项实测确认）

| 字段 | 用途 | 说明 |
|------|------|------|
| `provider` | Provider 配置 | DeepSeek 为内置 provider，仅需 `options.apiKey`（`{env:XXX}` 引用）+ `options.baseURL`；自定义 OpenAI 兼容需 `@ai-sdk/openai-compatible` |
| `model` | 默认模型 | `deepseek/deepseek-v4-flash`（v1.9 定案） |
| `mcp` | MCP 服务器 | local → `command` 数组；remote → `url` + `headers` |
| `skills` | 技能 | `paths` / `urls` |
| `plugin` | 插件 | npm 包或本地 ts/js 文件（`fractal`、`agents-priority`、superpowers、opencode-acp） |
| `permission` | 权限规则 | `"*": "ask"` / `"edit": "allow"` 等（方案 3.5） |
| `instructions` | 指令文件 | 预置规则 |
| `agent` | agent 定义 | 双星/工匠/参谋/军师 |
| `compaction` | 压缩 | `{"auto": false}`（使用 opencode-acp 时） |
