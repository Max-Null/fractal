# 分形-部署指南

> 版本：v1.0 ｜ 更新：2026-08-10 ｜ 读者：终端用户/测试
> 关联：docs/设计/分形-设计方案.md（交付章节）

## 一、安装包获取

分形以 **NSIS 安装包**交付，产物位于构建机的 `dist/oc-gui-0.1.0-setup.exe`（当前约 132MB）。

| 项 | 值 |
|----|----|
| 产物路径 | `dist/oc-gui-0.1.0-setup.exe` |
| 体积 | ~132MB（2026-08-10 瘦身，原 215.6MB） |
| 平台 | Windows x64（Win10/Win11） |
| 运行环境 | 无需预装 Node/OpenCode（内置 sidecar 1.18.15） |

### 重新打包

开发机执行：

```bash
npm run build:win
```

产物覆盖 `dist/oc-gui-0.1.0-setup.exe`。

## 二、安装步骤（另一台 Win11）

1. 拷贝 `oc-gui-0.1.0-setup.exe` 到目标电脑（U 盘/网盘/微信均可）
2. 双击运行安装 → 桌面自动创建「分形」快捷方式
3. **SmartScreen 提示**：安装包无代码签名，Windows 会警告「未知发布者」→ 点「更多信息」→「仍要运行」
4. 首次启动自动初始化预置包（agents/skills/plugins，零概念门槛）
5. 打开设置页，填入 **DeepSeek API Key**（唯一必填配置项）→ 开聊

## 三、首次启动初始化

- 预置包来源：安装目录 `resources/preset/`（agents-manifest.json 契约驱动）
- 初始化动作：拷贝到用户数据目录 `%APPDATA%\fractal\config\opencode\`（skills/agents/plugins）
- 用户无需手动安装任何插件/技能

## 四、体积构成说明（132MB）

| 组件 | 体积 | 性质 |
|------|------|------|
| Electron 运行时 | ~110MB | 硬性（Electron 43 打包压缩后） |
| opencode sidecar | 170MB（解压） | 产品硬约束：内置 OC、离线可用 |
| 应用代码 app.asar | ~13MB | 渲染层 bundle + 主进程依赖 |

> 瘦身历史（2026-08-10，提交 9971dcf）：删除误打包的 opencode 备份（-167MB）、renderer 依赖移 devDependencies（asar 218→13MB）、locales 裁剪（46.6→1.1MB）、排除 stage0/docs。

## 五、常见问题

| 问题 | 处理 |
|------|------|
| SmartScreen 未知发布者 | 「更多信息 → 仍要运行」（无代码签名，正常现象） |
| 首次启动卡顿 | 初始化预置包 + 启动 sidecar，稍候即可 |
| API Key 在哪填 | 设置页（唯一必填项） |
| 旧版本升级 | 直接覆盖安装，用户数据（会话/配置）保留在 `%APPDATA%\fractal` |
| 多实例 | 应用有单实例锁，重复启动会聚焦已有窗口 |

## 六、相关目录

| 路径 | 用途 |
|------|------|
| `%APPDATA%\fractal\` | 用户数据（配置/日志/预置拷贝） |
| `%APPDATA%\fractal\logs\` | serve.log + serve-crash-*.log（排查崩溃） |
| 安装目录 `resources\bin\` | 内置 opencode.exe sidecar |
| 安装目录 `resources\preset\` | 预置包（agents/skills/plugins） |
